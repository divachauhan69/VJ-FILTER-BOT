## Variables

### Required Variables
* <b>`BOT_TOKEN`: Create a bot using [@BotFather](https://telegram.dog/BotFather), and get the Telegram API token.
* `API_ID`: Get from [telegram.org](https://my.telegram.org/apps)
* `API_HASH`: Get from [telegram.org](https://my.telegram.org/apps)
* `CHANNELS`: File channel username or ID. Separate multiple by space
* `ADMINS`: Admin username or ID. Separate multiple by space
* `DATABASE_URI`: [MongoDB](https://www.mongodb.com) URI
* `LOG_CHANNEL`: Channel to log bot activities. Bot must be admin.</b>
